2. НАЗНАЧЕНИЕ ПРОЕКТА
--------------------------------------------------------------------------------
LOKED (Locked Olympiad Kiosk Environment) — защищённая олимпиадная среда для школ 
и олимпиадных центров.
- Клиент блокирует рабочий стол Windows, перехватывает системные сочетания клавиш,
  убивает запрещённые процессы (сторонние браузеры, Telegram, Discord, игры) и
  предоставляет ученику чистый рабочий стол с разрешёнными инструментами.
- Панель администратора позволяет учителю в реальном времени видеть все экраны
  компьютеров в классе, управлять таймером тура, транслировать объявления,
  дистанционно блокировать/разблокировать ПК и управлять мышью/клавиатурой.

Репозиторий: https://github.com/nadaroot/blockingforolympics.git (ветка main).

4. КЛЮЧЕВЫЕ МЕХАНИЗМЫ И ЛОГИКА
--------------------------------------------------------------------------------

[1] СЕКРЕТНАЯ КОМБИНАЦИЯ ВЫХОДА / РАЗБЛОКИРОВКИ:
- Комбинация клавиш: `Ctrl + Alt + Shift + L` (также слушает русскую раскладку: `Д`).
- Открывает модальное окно `#unlockModal`.
- Пароль по умолчанию: `admin` (настраивается учителем в конфиге).
- При вводе правильного пароля снимаются Win32 хуки и клиент разблокируется.

[2] РАБОЧИЙ СТОЛ (DESKTOP SURFACE):
- На рабочем столе отображаются:
  1. Системные приложения: Яндекс Контест, Редактор кода, Мои файлы, Калькулятор.
  2. Ярлыки сред разработки, настроенные учителем: PyCharm, VS Code, Python IDLE,
     PascalABC.NET, Code::Blocks, Блокнот и внешние ссылки.
  3. Файлы и папки участника из каталога `%USERPROFILE%\Desktop\LOKED_Workspace`.
- ИКОНКИ: используются оригинальные каноничные векторные логотипы (BASE_ICONS):
  официальный логотип Python (сине-жёлтый), официальная лента VS Code, официальный
  логотип PyCharm JetBrains, классический щит Pascal, кубики Code::Blocks и т.д.
- Контекстное меню ПКМ: создать файл Python/C++/Pascal/текст, создать папку, обновить.
  Двойной клик по приложению запускает его, по файлу — открывает во встроенном редакторе.

[3] НИЖНИЙ БАР (DOCK):
- Выполнен в стиле macOS (чистый CSS `:has()` с увеличением соседних иконок).
- ВАЖНО: В баре отображаются ТОЛЬКО те программы, которые ОТКРЫТЫ в данный момент!
  Если открытых программ нет — док автоматически скрывается (`.docker.empty`).
  Когда программа открывается — она появляется в доке со светящейся точкой активности.
  Когда программа закрывается (нажатие красной кнопки 🔴) — она исчезает из дока.

[4] ДИАЛОГИ ВВОДА (PROMPT & CONFIRM):
- Стандартный браузерный `window.prompt()` в Electron не работает (заблокирован).
- Вместо него реализованы встроенные асинхронные модальные окна:
  - `showPrompt(title, defaultValue, subText)` -> `#promptModal`
  - `showConfirm(title, message)` -> `#confirmModal`
  - Глобальные функции `window.prompt` и `window.confirm` переопределены.
  - Поддерживают автоматический фокус, Enter для подтверждения, Escape для отмены.
  - Используются при переименовании и создании файлов/папок.

[5] СЕТЕВОЕ ВЗАИМОДЕЙСТВИЕ И ОБНАРУЖЕНИЕ (DISCOVERY):
- Учительский компьютер запускает `LOKED-Admin.exe` (сервер порт 3000, UDP порт 41234).
- Компьютеры учеников при запуске отправляют широковещательный UDP-пакет
  `LOKED_DISCOVER` на адрес `255.255.255.255:41234`.
- Сервер учителя отвечает `LOKED_SERVER:3000`.
- Клиенты автоматически узнают IP-адрес учителя и подключаются по WebSocket.
- Ни ученикам, ни учителю НЕ требуется вводить IP-адреса вручную.
- Особенность школьной топологии: часто учительский ПК является шлюзом (gateway)
  для компьютеров класса.

[6] ЗАЩИТА И БЛОКИРОВКА (LOCKDOWN):
- `client/native/Locker.cs`: перехватывает вызовы низкоуровневых клавиш (Win, Alt+Tab,
  Alt+Esc, Ctrl+Esc, Alt+F4) через Win32 API `SetWindowsHookEx(WH_KEYBOARD_LL)`.
- `client/src/watchdog.js`: при старте выполняет `sweepOnStartup()` — мгновенный
  `taskkill /F /IM` по списку запрещённого софта (chrome, msedge, telegram, discord,
  игры и т.д.), затем постоянно контролирует запущенные процессы.
- Мультимониторность: при наличии второго монитора клиентское приложение блокирует
  второй экран отдельным окном блокировки.

5. КАК СОБИРАТЬ И ПУБЛИКОВАТЬ НОВЫЕ ВЕРСИИ
--------------------------------------------------------------------------------
1. Внесите необходимые изменения в код.
2. Проверьте синтаксис: `node --check client/src/shell/shell.js` и т.д.
3. Закоммитьте и отправьте в git:
   git add .
   git commit -m "Описание изменений"
   git push origin main
4. Создайте новый тег (например, v1.0.2) и отправьте его на GitHub:
   git tag v1.0.2
   git push origin v1.0.2
5. GitHub Actions runner (`windows-latest`) автоматически:
   - Запустит `npm run pack` (скрипт `scripts/pack.js`).
   - Скомпилирует `Locker.cs` через `csc.exe`.
   - Соберёт standalone `LOKED-Client.exe` и `LOKED-Admin.exe` с упакованными ресурсами.
   - Создаст ZIP-архивы `LOKED-Client-win-x64.zip` и `LOKED-Admin-win-x64.zip`.
   - Создаст GitHub Release и прикрепит все 4 файла.

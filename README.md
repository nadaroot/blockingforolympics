# LOKED — Locked Olympiad Kiosk Environment

Профессиональная система изолированной рабочей среды для проведения олимпиад по информатике и школьных контестов в локальной сети (аналог программного обеспечения для компьютерных клубов).

---

## 🌟 Возможности системы

### 1. Клиентская станция ученика (`Loked Client`)
* **Полноэкранный изолированный рабочий стол:** заменяет рабочий стол Windows, работает в режиме `Kiosk` (поверх всех окон).
* **Аппаратные блокировки (Win32 Hook):**
  * Заблокированы системные клавиши: `Win`, `Win + R` (Выполнить), `Win + E`, `Win + D`, `Win + X`.
  * Заблокированы сочетания переключения: `Alt + Tab`, `Alt + Esc`, `Alt + F4`, `Ctrl + Esc`.
  * Отключен Диспетчер задач (`Ctrl + Shift + Esc` и через `Ctrl + Alt + Del`).
* **Безопасный Chromium-браузер:**
  * **Полностью отсутствует адресная строка и поиск:** браузер умеет открывать только URL, назначенный учителем.
  * **Вырезано контекстное меню (ПКМ):** невозможно нажать «Найти в Google», «Просмотреть код» или «Печать».
  * **Отключен DevTools (`F12`):** инспектор кода и консоль разработчика заблокированы.
  * **Белый список доменов:** переход на любые внешние сайты пресекается с выводом предупреждения.
* **Process Watchdog (Сторожевой пес):**
  * Постоянный мониторинг запущенных процессов. При попытке запустить сторонний браузер (Chrome, Edge, Firefox), мессенджер (Telegram, Discord), игру или софт с флешки — процесс принудительно убивается в течение 1–2 секунд, а в журнал учителя отправляется тревожный сигнал.
* **Экстренный мастер-пароль:**
  * Возможность временно разблокировать ПК прямо на месте по паролю (по умолчанию: `admin`, сочетание клавиш `Ctrl + Alt + Shift + L`).

---

### 2. Панель управления учителя (`Loked Admin`)
* **Два режима работы:**
  * **Десктопное приложение Windows** (`run-admin-desktop.bat`).
  * **Веб-интерфейс в браузере** (`http://localhost:3000` или по локальному IP `http://192.168.x.x:3000`), доступный с любого ноутбука, планшета или смартфона в школьной сети.
* **Автопоиск клиентов (Zero Config):**
  * Клиентские ПК находят сервер учителя по UDP-широковещательному запросу без ручного ввода IP-адресов.
* **Сетка мониторинга ПК:**
  * Живой статус каждого компьютера (готов, в контесте, заблокирован, нарушение).
  * **Просмотр экрана (Live Screenshot):** учитель кликает на кнопку «Экран» и видит снимок монитора ученика.
* **Синхронизированный таймер олимпиады:**
  * Запуск, пауза, остановка и обратный отсчет времени транслируются на все мониторы класса в реальном времени.
* **Управление ярлыками и контестом:**
  * Настройка ссылки на контест (Яндекс.Контест, Codeforces, локальный Ejudge и др.).
  * Включение/отключение сред разработки: **PyCharm**, **PascalABC.NET**, **Code::Blocks (C++)**, **VS Code**, **Python IDLE**, **Калькулятор**, а также добавление любых своих `.exe`.
* **Быстрые объявления:**
  * Рассылка текстовых оповещений (например: «Осталось 15 минут») прямо на экраны учеников поверх всех окон.

## 🚀 Быстрый запуск

### На компьютере учителя:
1. Запустите:
   ```cmd
   run-admin-desktop.bat
   ```
   *(или запустите `run-server.bat` и откройте в браузере `http://localhost:3000`)*.
2. В панели управления введите ссылку на контест и отметьте нужные ярлыки.

### На компьютерах учеников:
1. Запустите:
   ```cmd
   run-client.bat
   ```
2. Клиент автоматически найдет сервер учителя в локальной сети, перейдет в полноэкранный режим и загрузит ярлыки с таймером.

## 🛠 Архитектура файлов проекта

```
loked/
├── server/                    # Серверная часть и веб-панель
│   ├── src/
│   │   ├── index.js          # Express + Socket.IO + REST API + Heartbeat
│   │   ├── config.js         # Загрузка и сохранение настроек олимпиады
│   │   └── discovery.js      # UDP Broadcast авто-обнаружение по локалке
│   └── public/               # Веб-интерфейс (HTML, CSS, JS)
│       ├── index.html        # Сетка ПК, управление олимпиадой, модальное окно экрана
│       ├── style.css         # Темная современная кибер-тема
│       └── app.js            # Логика реального времени и звуковые алерты
│
├── client/                    # Клиентская киоск-оболочка
│   ├── src/
│   │   ├── main.js           # Electron ядро: окна, полноэкранный режим, запуск софта
│   │   ├── network.js        # Связь с сервером по UDP и Socket.IO
│   │   ├── watchdog.js       # Мониторинг и принудительное завершение запрещенных программ
│   │   ├── locker-manager.js # Управление низкоуровневым Win32-блокировщиком
│   │   ├── shell/            # Рабочий стол ученика (UI, ярлыки, часы, баннеры)
│   │   └── browser/          # Безопасный Chromium (без омнибокса, фильтр переходов)
│   └── native/
│       ├── Locker.cs         # C# хук WH_KEYBOARD_LL и реестровые политики Windows
│       └── locker.exe        # Скомпилированный нативный бинарник
│
├── admin-desktop/             # Десктопная Electron-оболочка для учителя
│   └── main.js
│
├── run-server.bat             # 1-клик запуск сервера
├── run-admin-desktop.bat      # 1-клик запуск админки учителя
├── run-client.bat             # 1-клик запуск станции олимпиадника
└── build-locker.bat           # Скрипт сборки нативного модуля csc.exe
```

## 🔑 Пароль администратора по умолчанию
* Пароль для локальной разблокировки ПК: `admin`
* Хоткей вызова окна ввода пароля на клиенте: `Ctrl + Alt + Shift + L` (или кнопка в правом нижнем углу рабочего стола).
* Пароль можно изменить в веб-панели во вкладке «Настройки и Ярлыки».

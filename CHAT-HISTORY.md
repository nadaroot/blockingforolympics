## Часть 1. Браузерная версия на порту 4888

**Запрос:** «сделаем браузерную версию на 4888 где будет показывать актуальный вариант, сейчас рабочий стол закрыт чёрным».

**Проблема:** клиент открывает окно в kiosk-режиме (`main.js` → `frame:false, fullscreen:true, kiosk:true`), поэтому в обычном браузере интерфейс посмотреть нельзя.

**Сделано:**
- `scripts/preview.js` — zero-dep HTTP-сервер на `127.0.0.1:4888`, отдаёт `client/src/shell/*` с `Cache-Control: no-store`.
- `scripts/preview-shim.js` — мок `window.require('electron')`: `ipcRenderer.invoke/on/send`, мок-конфиг, мок рабочей папки.
- `package.json` → скрипт `start:preview`.
- Тестовые режимы превью: `?desktop=1`, `?win=<key>&restore=1`, `?menu=1`, `?mbmenu=<menu>`.

## Часть 2. Три бага/просьбы по интерфейсу

**Запросы:**
1. Контест открывается окном, а должен сразу на весь экран; и когда в окне — фон чёрный, а не прозрачный.
2. То же со всеми программами.
3. ПКМ на рабочем столе должен быть как в Windows, с авто-подстановкой шаблона по расширению.

**Сделано:**
- `shell.js` → `openWindow()` стал открывать окно развёрнутым (позже переделан обратно в плавающее окно — см. часть 6).
- Прозрачность: `shell.css` — `rgba(...)` + `backdrop-filter` для `.mac-window`, шапок, тулбаров, тела редактора/калькулятора.
- Фон обоев переведён с почти чёрного `#030304` на мягкий градиент.
- `main.js` — внешние программы стартуют развёрнутыми: `start "" /MAX "<exe>"`.
- ПКМ-меню переработано в Windows-стиль: `Создать ▸` (папка, txt, py, cpp, c, pas, java, cs, «любое расширение…») + подменю с авто-открытием по наведению и переворотом у края экрана.
- `shell.js` → `FILE_TEMPLATES` (18 расширений) + `detectExtension()`: шаблон определяется по тому, что пользователь ввёл; если расширения нет — оно дописывается само.
- Ошибка «файл уже существует» теперь показывается пользователю.

## Часть 3. Режем иконки и Touch Bar

**Проблема (найдена):** `.docker` был в потоке flex с `min-height:100vh`; когда док появлялся, он сжимал `.desktop-surface` до нуля — иконки обрезались до тонкой полоски.

**Сделано:**
- `.docker` → `position: fixed` (вынесен из потока), добавлено `.docker.force-hidden`.
- Touch Bar (`#touchBar`): контекстные кнопки в зависимости от активного окна (`TOUCHBAR_LAYOUTS`, `TOUCHBAR_ACTIONS`), сворачивание, обновление при `bringToFront`/`closeWindow`/`minimizeWindow`.

## Часть 6. Перетаскивание иконок, macOS-курсоры, один клик по иконке

**Запросы:** реальное выделение левой кнопкой; курсор как в macOS; клик по иконке в доке не должен закрывать.

**Сделано:**
- Полноценная рамка выделения: `mousedown/mousemove/mouseup` по `.desktop-surface`, `markMarqueeSelection()`, множественное выделение `selectedIds`, `Ctrl+A` — выделить всё, защита от «клик сбрасывает рамку» (`suppressClickClear`).
- macOS-курсоры как SVG data-URI: стрелка, I-beam, рука; `--cursor-arrow`, `--cursor-ibeam`; `nwse-resize` у resize-хендла сохранён.
- Док: левый клик открывает/показывает; правый клик → мини-меню «Показать / Скрыть / Закрыть» (собирается динамически из существующих классов `.context-menu`).

## Часть 9. Provisioning и PyCharm-lockdown (итог)

`provisioner.js`:
- Каталог: Python 3.8, Free Pascal 3.x, Code::Blocks 17.12+, PascalABC.NET 3.x, PyCharm Community.
- `detectAll()` — только проверка; `installApp()` — winget, при неудаче тихая установка из URL; `ensureEnvironment()` — сводный отчёт.
- При старте клиента выполняется только детект, установка — по IPC.

`pycharm-lockdown.js` (без патча бинарников):
- `disabled_plugins.txt` со всеми id плагинов (это отключает и AI Assistant).
- Пользовательский vmoptions: `-Djb.consents.endurance.enabled=false`, `-Djb.privacy.policy.text=##0.0.0.0`, `-Didea.trust.all.projects=true`.
- `auditPyCharm()` при каждом запуске: все ли плагины отключены, нет ли AI-плагинов.
- Опционально — записи в `hosts` на `0.0.0.0` (только при правах администратора).

- Запущено на localhost: превью `http://127.0.0.1:4888` и клиент Electron в **оконном** режиме (`--windowed`, без хука клавиатуры и без убийства процессов).

## Часть 12. Авторизация Git и выкладка

```powershell
git config --global credential.helper manager
git credential-manager github login     # один раз, откроется браузер
git add -A; git commit -m "..."; git push origin main
git tag v1.0.1; git push origin v1.0.1  # сборка приложений в GitHub Actions
```
Креды хранятся в Windows Credential Manager — пароль больше не спрашивается. Автопуш после коммита — хук `.git/hooks/post-commit` (создаётся вручную, с окончаниями строк LF).
